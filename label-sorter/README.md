# 標籤依儲位排序

把出貨標籤 PDF（例如 `0924S-1.pdf`）依照庫存盤點 Excel 裡的「儲位」重新排列，
輸出 `0924S-1_依儲位排序.pdf`，撿貨時照著儲位 A0 → A3 → B1 → … → Z 走一趟就好。

## 使用方式

1. 用 Chrome / Edge 直接打開 `index.html`（不用安裝，需要網路載入函式庫）
2. 第一次使用時匯入「庫存盤點 Excel」，之後瀏覽器會記住，不用每次匯入；
   儲位有變動時按「更換庫存表」換新的
3. 選或拖曳「標籤 PDF」，按「排序並下載」

畫面會顯示目前使用的庫存表版本，版本號取自檔名裡的日期，
例如 `庫存盤點表_20260924_1790228665656.xlsx` → **V20260924**。
超過 7 天的版本會以黃色標示提醒。

## 排序規則

- 每張標籤讀取第 3 行（商品名）和第 4 行（規格[貨號），對應到 Excel 的「系統商品名」「規格一/規格二」「選項貨號」
- 依「實際儲位」排序（空白時用「儲位」），同一儲位內依選項貨號，再依原本順序
- 右上角第二行規格ID（例如 `89558606923`）的後三碼 **923** 在原位置放大 1.5 倍
- 規格文字對不上時，用同商品裡最相近的規格推測（表格黃色）；完全找不到的排在最後（表格紅色）

所有處理都在瀏覽器內完成，檔案不會上傳。
